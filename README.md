# 毕设接单管理助手

一个基于 Vue + Electron + SQLite 的本地桌面项目管理工具，用于跟踪毕设接单、返修、收款和交付状态。

## 当前版本

- 应用版本：`6.5.4`
- 技术栈：`Vue 3`、`Vite`、`Electron`、`better-sqlite3`

## 开发命令

```bash
npm ci
npm run dev
npm run build:mac -- --arm64
npm run build:win
```

## 6.5.0 更新说明

### 浅色与深色外观

- 在「系统设置 → 基础偏好 → 外观」切换浅色与深色。默认浅色，深色使用中性近黑背景。软件会记住本机的选择，重启后恢复。

### 左侧筛选、订单列表与底部操作

- 届数和类型保留原有按钮布局。学校、专业、接单人、处理人集中在「精细筛选」中，两列排列，并显示已启用的精细筛选数量。
- 缩短状态筛选、排序、分组和订单计数所占的高度。窗口较矮时，展开的精细筛选浮在侧栏右侧，给订单列表留出更多空间。

- 底部恢复两行布局，第一行是全宽「新建接单项目」，第二行是等宽的同步、数据统计、设置和退出登录按钮。

### 右侧订单详情与项目文件

- 「项目文件区」排在首位，打开订单时默认显示。「修改意见与迭代」位于第二项，并显示轮次数量。移除「全部视图」和「财务与结算」页签，收款和退款信息仍可在订单详情查看。
- 项目文件夹卡片、拖拽上传区和附件区域适配浅色与深色外观。右侧标题旁的「待补充题目」标签单独加深。
- 设计状态按钮、下拉选项及设置中的状态标签提高对比度。「暂未购买」「已购买-未优化」用琥珀色，「已购买-已优化」用绿色，「客户提供」用中性色。下拉菜单会突出标出当前状态。

### 修改意见与迭代

- 调整反馈列表、附件和输入区的样式。可在列表内点击编辑按钮或双击正文，直接修改一条意见。支持将当前轮次的待办意见批量标记为完成。

### 删除订单

- 改为居中的紧凑弹窗，展示订单编号、题目和将受影响的记录。默认保留项目文件夹，勾选后才会同时删除文件夹，并显示完整路径与警告。

- 提高顶部搜索、精细筛选下拉菜单、新建订单输入提示及「保存后将在根目录下创建文件夹」等建档说明的对比度。

## 订单编号规则

- 新建订单会自动生成 `毕业届年份-服务类型编码-流水号` 格式的订单编号，例如 `2027-BS-0001`。
- 设置固定前缀后，编号格式为 `固定前缀-毕业届年份-服务类型编码-流水号`，例如 `WH-2027-BS-0001`。
- 群聊名称留空时，会默认使用自动生成的订单编号；新建订单时手动填写群聊名称，则该内容同时作为订单编号。
- 毕设论文订单会按“是否包含设计”区分编码：包含设计为 `BS`，不含设计为 `BP`。
- 设计定制对应 `SD`；特殊订单中，开题报告对应 `KR`，图例绘制对应 `FD`，PPT制作对应 `PP`，其他特殊服务对应 `OS`。
- 格式修改、外文翻译和论文降重的默认编码分别为 `FM`、`ET` 和 `PR`。
- 从 6.4.0 起，可在设置页分别修改以上十种默认编码。编码仅接受英文字母和数字，自动转为大写，最长 12 个字符；留空恢复对应类型的默认编码。
- 各类型编码独立生效，例如修改 `BS` 不会影响 `BP`。设置只影响后续自动生成的编号，已有编号和手动填写的群聊名称保持原样。
- 6.3.0 的统一“业务简写”覆盖设置不再参与编号生成，升级后请按服务类型设置需要的编码。

## 历史输入建议

- 学校、学院、专业、接单人、处理人和指导教师输入框，会显示当前账号已有订单中的历史值。
- 点击建议前的移除图标，可单独隐藏该项，不会选择该值或修改已有订单。隐藏记录按账号和字段分别保存，重新打开窗口或重启软件后仍生效。
- 移除后仍可手动输入该值。成功新建使用该值的订单后，建议会重新出现；取消创建或保存失败不会恢复，编辑已有订单也不会解除隐藏。

## 版本管理约定

- Git 仓库只保存源码、配置、文档。
- `node_modules/`、`dist/` 等构建产物不提交。
- 大体积安装包如需随版本一并归档，使用 Git LFS 管理。
- 本地数据库和运行时数据不提交。
- 每次正式发布时：
  1. 更新 `package.json` 版本号。
  2. 提交代码。
  3. 打标签，如 `v5.2.0`。
  4. 将安装包上传到 GitHub Releases 做归档。

详细归档记录见 [ARCHIVE.md](./ARCHIVE.md)。
