# 毕设接单管理助手

一个基于 Vue + Electron + SQLite 的本地桌面项目管理工具，用于跟踪毕设接单、返修、收款和交付状态。

## 当前版本

- 应用版本：`6.3.0`
- 技术栈：`Vue 3`、`Vite`、`Electron`、`better-sqlite3`

## 开发命令

```bash
npm install
npm run dev
npm run build:win
```

## 6.3.0 升级亮点

- 新建订单时，手动填写群聊名称可直接作为订单编号，避免预先分配的编号被系统自动编号覆盖。
- 设置页新增订单编号规则，可配置固定前缀和业务简写，并实时预览最终编号。
- 自定义规则留空时，继续兼容原有按订单类型生成 BS、BP、FM 等业务简写的逻辑。
- 自动检测重复订单编号，防止同一账号下出现重复编号。

## 6.2.0 升级亮点

- 新建订单新增套餐选项，可选择省钱套餐、省心套餐或超级 VIP 套餐，也可以留空；套餐会同步显示在订单卡片和订单详情中。
- 处理人为“本人”时不再要求填写派单金额，相关统计和结算数据也会自动排除本人处理订单的派单费用。
- 毕设论文题目允许暂时留空，并提供“待补充题目”提醒，方便后续持续跟进。
- 题目未确认时，项目文件夹使用“题目暂未确认”作为名称后缀；补充题目后可同步更新文件夹名称。
- 已有正式题目再次修改时，可由用户选择“同步修改文件夹并保存”或“仅保存订单信息”。

## 5.9.0 升级亮点

## 订单编号规则

- 新建订单会自动生成 `毕业届年份-服务类型编码-流水号` 格式的订单编号，例如 `2027-BS-0001`。
- 群聊名称留空时，会默认使用自动生成的订单编号；新建订单时手动填写群聊名称，则该内容同时作为订单编号。
- 毕设论文订单会按“是否包含设计”区分编码：包含设计为 `BS`，不含设计为 `BP`。
- 设计定制对应 `SD`；特殊订单中，开题报告对应 `KR`，图例绘制对应 `FD`，PPT制作对应 `PP`，其他特殊服务对应 `OS`。

## 5.8.0 升级亮点

- 订单详情页新增尾款“一键结清”，确认后可直接将已收金额补齐到全款金额。
- 新建订单文件夹按毕业届归档，路径结构升级为 `根目录/2027届/业务类型/学校/专业/2027-项目名`。
- 设置页新增历史文件夹按毕业届整理工具，支持预览后复制迁移并更新数据库路径。

## 5.2.0 升级亮点

- 同步身份从本地自增 `userId` 升级为账号稳定标识，不再因为 `user-1 / user-2 / user-3` 分叉。
- 新版本会自动兼容旧版 `user-*` 同步目录，便于双机从旧结构平滑迁移。
- 多机迁移导入时会保留订单、轮次、反馈的同步 `syncUuid`，避免导入后失去同步能力。
- 同步状态说明已明确提示新版使用稳定账号标识。

## 版本管理约定

- Git 仓库只保存源码、配置、文档。
- `node_modules/`、`dist/` 等构建产物不提交。
- 大体积安装包如需随版本一并归档，使用 Git LFS 管理。
- 本地数据库和运行时数据不提交。
- 每次正式发布时：
  1. 更新 `package.json` 版本号。
  2. 提交代码。
  3. 打标签，如 `v5.2.0`。
  4. 将安装包上传到 GitHub Releases 做归档。

详细归档记录见 [ARCHIVE.md](./ARCHIVE.md)。
